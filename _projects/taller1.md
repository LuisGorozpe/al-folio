Taller: Practicas avanzadas de programación con Python y  Una introducción a las Series De tiempo.
Tallerista: M.c. Luis Enrique Ascencio Gorozpe.
El propósito de este taller es hacer una introducción sobre buenas practicas de programación en python así como la teoría clásica de series de tiempo y su modelado con python. 
Sesión 1-2: Introducción al Taller (3 horas).
En estas sesiones vamos a introducir las herramientas principales para nuestro taller. Vamos a revisar el entorno del editor de código Visual Code Studio, su integración con entornos virtuales e implementaciones de Python como Anaconda así como extensiones para herramientas como Docker y manejado de versiones con Git.
Sesión 3-4: Introducción a las series de tiempo y Modelos Clásicos (3 horas).
En estas sesiones vamos a definir formalmente lo que es una serie de tiempo desde el punto de vista de la teoría  de la probabilidad, vamos a caracterizar alguna propiedades deseables para su modelado. También abordaremos  algunos de los  modelos clásicos de series de tiempo y haremos algunas simulaciones.
Sesión 5-6: paquetes y herramientas avanzadas para Series de tiempo en Python y R (3 horas).
En estas sesiones vamos manejar algunas librerías y Frameworks avanzados de Python y R para modelar, ajustar y predecir series de tiempo.
Sesión 7-8:  Temas Extras Sobre Series de Tiempo: Heterocedasticidad, Series Multivariadas, Redes Neuronales - LSTM, etc..(3 Horas).
En esta sesión vamos a platicar sobre modelos mas generales de series de tiempo como modelos  multivariados  o los modelos con heterocedasticidad , vamos a revisaremos código de python y R ademas de un poco de la teoría matemática. También revisaremos algunos libros y artículos que discuten enfoques mas modernos de series de tiempo.
Sesión 9-10:  Documentación, Presentación y Estilizado de código en Python (3 Horas).
En estas sesiones revisaremos algunas buenas practicas de programación para documentar, presentar y estilizar código. vamos a usar  herramientas externas que nos ayudaran a estilizar, presentar y compartir nuestro código garantizado la replicabilidad de nuestro código.

Sesión Extra - 11-12: Uso de herramientas AI para la programación, creación y asistencia en la investigación: 
En esta sesión vamos a revisar y utilizar herramientas de AI mas allá de ChatGPT para la creación, asistencia y presentación de código. Ademas veremos algunos ejemplos de uso sencillos mediante software opensource para su ejecución en local. Finalmente veremos algunos ejemplos de AI agents que pueden servir para la asistencia en la investigación y concluiremos discutiendo las tendencias actuales para el uso de LLM y herramientas AI en la industria y uso cotidiano.

Requisitos y preparación para las sesión 1-2.
Requisitos: Conocimientos básicos de probabilidad y estadística, una computadora con alguna implementación de Python (de preferencia Anaconda) y Rstudio.
